# Contributing to ElastNetMT

Development follows the [repository agent guide](https://github.com/uibcdf/elastnetmt/blob/main/AGENTS.md)
and the synchronized MolSysSuite policies. Start with the maintained
[developer guide](https://github.com/uibcdf/elastnetmt/tree/main/devguide)
for architecture, units and testing.

The required source range is Python 3.11–3.14; routine development uses the
suite's Python 3.14 environment. Public installed support is tracked in
[#19](https://github.com/uibcdf/elastnetmt/issues/19).

Open an owning issue for a bug or proposal. Keep independently useful
scientific operations in their owning module and call provider tools for
shared molecular functionality. Check the affected numerical contract and
the reporting indexes before committing.
